BJProb is a Java Monte Carlo Simulator that models the outcomes of billions of blackjack hands based on different strategies and configurable table rules.

Features:
- configurable multi-deck shoe simulation
- configurable deck penetration
- player hand logic
- card counting logic
- configurable dealer rules
- dealer hand logic
- configurable bet spread and bankroll
- popular card counting deviations
- expected value and risk of ruin statistical analysis


Purpose:
I built this to explore the probability and statistics behind blackjack simulations while improving my skills in Java, object-oriented programming, simulation design, and statistical analysis.


Running:
1. Clone the repository.
2. Open it in IntelliJ IDEA or another Java IDE.
3. Run `Main.java`.
